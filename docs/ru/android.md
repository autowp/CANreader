# Совместимость с Android

Для CANreader требуется Android 6.0 (API 23) или новее — это соответствует настроенному в приложении минимальному уровню SDK.

USB host/OTG требуется только для USB serial-адаптеров. Телефон или планшет должен поддерживать режим USB host; также могут понадобиться OTG-переходник и питание для подключённого устройства.

Bluetooth-подключение использует Bluetooth Classic Serial Port Profile (SPP). Сначала выполните сопряжение адаптера в настройках Android. На Android 12 и новее предоставьте запрошенное разрешение на устройства поблизости/Bluetooth.

Сетевое подключение использует UDP: телефон и адаптер должны иметь возможность обмениваться данными по сети. USB OTG для него не требуется.
