# CANreader для Android

CANreader — приложение Android для мониторинга и передачи CAN-кадров через адаптеры с протоколом CanHacker.

- Минимальная версия Android: 6.0 (API 23).
- Поддерживаемые функции и требования к подключению описаны в [документации проекта](README.md).
- [Открыть страницу приложения в Google Play](https://play.google.com/store/apps/details?id=com.autowp.canreader).

Доступность приложения в магазине может зависеть от региона и совместимости устройства.
