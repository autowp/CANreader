# Known issues

No confirmed app-specific defects are currently documented on this page. If you find a reproducible problem, include the app version, Android version, connection type, adapter/firmware model, and steps to reproduce it in a repository issue.

## Legacy hardware notes

Older project notes mention Arduino Uno startup timing with some CanHacker software and an unintended reset caused by the desktop CanHacker `Reset` command. These observations concern legacy board/firmware combinations; their current status has not been verified and they are not confirmed defects in this Android app.

For connection requirements, see [supported adapters](adapters.md).
