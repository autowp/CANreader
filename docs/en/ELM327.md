# ELM327 status

The Android app does not currently provide an ELM327 connection option. The ELM327 protocol is intended primarily for OBD-II diagnostic requests and is not interchangeable with the CanHacker command protocol used by the app.

Although legacy ELM327-related source files may exist in the repository, they are not exposed as a supported connection in the app. Do not assume that a USB or Bluetooth ELM327 adapter can be used as a CANreader adapter.

Use an adapter implementing the CanHacker protocol instead; see [supported adapters](adapters.md).
